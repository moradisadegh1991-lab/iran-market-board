# تابلوی بازار — اپ اندروید

پوسته Capacitor. **رابط کاربری کامل داخل خود APK است** و بدون اینترنت هم باز می‌شود؛ فقط داده‌ها از سرور Vercel گرفته می‌شوند.

## چرا این ساختار

- کل HTML/CSS/JS و فونت وزیرمتن داخل APK است. هیچ CDN‌ای در کار نیست، چون CDN دقیقاً همان‌جا از کار می‌افتد که اینترنت ضعیف است.
- آخرین داده دریافتی در حافظه دستگاه ذخیره می‌شود. اگر اینترنت نباشد، همان اعداد با **ذکر زمان دریافت** نشان داده می‌شوند، نه صفحه خالی.
- منوی کشویی مثل اپ‌های بازار ایرانی: نمای کلی، ریسک، کریپتو، میم‌کوین، بورس، سبد، وضعیت منابع.

## ساخت APK

```bash
cd android-app
npm install
node set-url.mjs https://YOUR-APP.vercel.app   # آدرس دیپلوی خودتان
npx cap add android                             # فقط بار اول
npx cap sync android
npx cap open android                            # یا: cd android && ./gradlew assembleRelease
```

برای انتشار در مایکت و کافه‌بازار، همان `new-android-app.sh` و `release.sh` خودتان روی این پوشه کار می‌کنند؛ فقط `www/` را به‌عنوان webDir بدهید.

## نکته‌ای که بدون آن اپ کار نمی‌کند

اپ Capacitor از مبدأ `https://localhost` بالا می‌آید، پس هر درخواستش به سرور **cross-origin** است. برای همین `middleware.ts` در خود پروژه Next اضافه شده و روی مسیرهای **فقط-خواندنی** (`/api/snapshot`, `/api/chart`, `/api/swing`, `/api/simulate`) هدر CORS می‌گذارد.

مسیرهایی که وضعیت را تغییر می‌دهند (`/api/paper`, `/api/holdings`, `/api/telegram`, `/api/ingest`) عمداً باز نشده‌اند تا یک صفحه وب دلخواه نتواند از داخل مرورگر به حساب شما دستور بدهد.

پس **قبل از ساخت APK، نسخه جدید Next را روی Vercel دیپلوی کنید**، وگرنه اپ صفحه خالی نشان می‌دهد.

## دارایی‌های من

فهرست دارایی‌ها **فقط روی همین گوشی** ذخیره می‌شود (localStorage) و هیچ‌چیز به سرور فرستاده نمی‌شود. دلیلش امنیتی است: API دارایی‌های سرور رمز مدیر می‌خواهد، و گذاشتن آن رمز داخل یک APK منتشرشده یعنی هر کسی که فایل را باز کند به حساب شما دسترسی دارد.

- تاریخ خرید به هجری شمسی وارد می‌شود؛ تعداد روزهای هر ماه با کبیسه‌بودن سال تنظیم می‌شود (اسفند ۱۴۰۵ = ۲۹ روز) و تاریخ آینده رد می‌شود.
- ارزش‌گذاری با آخرین قیمت‌های دریافتی انجام می‌شود. بیت‌کوین و اتریوم در تابلو **دلاری**‌اند و در نرخ تتر ضرب می‌شوند؛ اگر نرخ تتر نباشد، آن قلم «قیمت در دسترس نیست» می‌گیرد و در جمع کل حساب نمی‌شود — به‌جای آنکه عدد دلاری به‌جای تومان جمع بزند.
- این صفحه بدون اینترنت هم کامل کار می‌کند (افزودن، حذف، مشاهده)؛ فقط قیمت روز به آخرین داده دریافتی وابسته است.

## ساخت خودکار با GitHub Actions

فایل `.github/workflows/build-android.yml` در ریشه پروژه است. با `workflow_dispatch` یا تگ `v*` اجرا می‌شود.

| Secret | لازم؟ | توضیح |
|---|---|---|
| `BOARD_URL` | بله | آدرس دیپلوی، داخل بسته نوشته می‌شود |
| `ANDROID_KEYSTORE_B64` | اختیاری | خروجی `base64 -w0 my.keystore` |
| `KEYSTORE_PASSWORD` · `KEY_ALIAS` · `KEY_PASSWORD` | اختیاری | برای امضای نسخه release |

اگر کلید امضا ندهید، به‌جای شکست خوردن، APK نسخه debug می‌سازد تا بتوانید نصب و تست کنید. خروجی در artifact با نام `market-board-apk`.

## محدودیت‌ها

- بخش‌هایی که رمز مدیر می‌خواهند (معامله برخط، دارایی‌های من، ربات) در اپ نیستند؛ آن‌ها از خود سایت انجام می‌شوند.
- آیکون و اسپلش پیش‌فرض Capacitor است؛ اگر طرح دارید در `android/app/src/main/res` جایگزین کنید.
